# 豆包语音输入（绿色免安装版）

按住**右 Alt** 说话，松开后文字自动出现在光标处。整程序放在文件夹里，**不需要管理员权限、不注册输入法、不写系统目录**。

---

## 一、怎么用

1. 双击 `启动豆包语音输入.cmd`（不会弹 UAC）。
2. 右下角出现一个短提示"✅ 就绪"，之后它就在后台待命（托盘区看不到图标是正常的，它是个隐藏的常驻进程）。
3. 在任何能打字的地方：**按住右 Alt** → 说话 → **松开**。
   - 屏幕上方会出现"🎤 正在听…" → 松开后变"⏳ 识别中…" → 文字自动贴到光标处。
4. 退出：任务管理器里结束 `DoubaoVoice.exe` 即可（也可在配置里改用别的热键）。

识别延迟：说话时长 + 约 2~4 秒（实测 3 秒语音 ≈ 5 秒出字，其中约 2 秒是建立云端连接）。

---

## 二、目录结构

```
DoubaoVoicePortable\
  app\                    主程序（PyInstaller 打包，含 Python 运行时、frida、音频库）
  runtime\v0.9.0.0\       豆包输入法自己的语音引擎（从官方安装目录复制，已去掉拼音词库）
  data\                   配置与日志（config.json、logs\app.log、last_recording.wav）
  启动豆包语音输入.cmd
```

整个文件夹可以直接拷到 U 盘或另一台电脑使用。

**已实测**：在一台"从未安装过豆包输入法"的等价环境（清空用户配置目录）下运行，识别依旧正常，因此这个绿色包不依赖本机装过豆包，也不需要它的任何账号登录。

## 四、配置（`data\config.json`）

| 字段 | 默认 | 说明 |
| --- | --- | --- |
| `hotkey` | `right alt` | 可选：`right alt` / `left alt` / `right ctrl` / `left ctrl` / `caps lock` 等 |
| `suppress_hotkey` | `false` | 设为 `true` 时按住热键不会传给它后面的程序（例如避免触发 AltGr） |
| `min_duration_sec` | `0.4` | 短于该时长的按键忽略 |
| `injection` | `paste` | 目前只实现剪贴板 + Ctrl+V 注入 |
| `restore_clipboard` | `true` | 粘贴后把剪贴板恢复成原内容 |
| `show_overlay` | `true` | 是否显示录音/识别浮层 |
| `asr_timeout_sec` | `60` | 单次识别超时 |

改完配置后重启程序生效。

## 五、它是怎么工作的（以及为什么不违反"无管理员"）

1. 程序用低级键盘钩子监听右 Alt 的按下/松开；
2. 用 WASAPI 录 16 kHz 单声道 PCM，存成临时 WAV；
3. 调用**豆包输入法自己的语音引擎**（`runtime\v0.9.0.0\ImeService.exe --test-sami`）做识别；
4. 把识别结果写进剪贴板，模拟 Ctrl+V 贴到当前光标，然后恢复剪贴板。

关键点：`ImeService.exe` 的原始清单写着 `uiAccess="true"`，普通用户直接运行会被系统拒绝（报"需要提权"）。本产品在**副本文件**里把该声明就地改成 `uiAccess="false"`（等长字节改写，只动这一个副本），因此可以普通用户运行；这也是为什么必须用本目录内的 `runtime`，不要换成别处的副本。

## 六、已知限制与注意事项

- **需要联网**：识别在豆包云端完成，断网时无法出字。
- **随版本更新可能失效**：识别链路复用厂商私有接口，豆包输入法升级后 `runtime` 里那两个补丁点可能需要重新定位（这就是为什么 `runtime` 是固定版本、不跟随官方自动更新）。
- **日志已被厂商脱敏**：引擎日志里中文会显示成 `X`（厂家隐私设计），不影响实际粘贴到你光标处的文字——产品读取的是引擎返回的原始结果。
- **不能粘贴到管理员权限窗口**：Windows 的 UIPI 限制，普通权限程序无法向提权窗口注入按键。
- **公司电脑合规**：语音音频会上传到豆包云端，请确认符合你所在公司的数据规定；另外在公司设备上运行未授权软件本身也可能违反 IT 政策。
- **本程序不含任何广告、后台收集**：唯一的网络访问就是识别音频。

## 七、卸载

1. 结束 `DoubaoVoice.exe` 进程；
2. 直接删除 `DoubaoVoicePortable` 整个文件夹；
3. （可选）删除 `%APPDATA%\DoubaoIme` —— 那是识别所需的设备缓存，删掉后首次识别会重新生成。

不会残留服务、计划任务、系统输入法条目或机器级注册表项。
