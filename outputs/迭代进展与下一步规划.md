## 二、实测数据（本机，海康/普通用户权限）

### 迭代 2 的关键实验
把 8 秒静音 WAV 交给引擎，启动 1.2 秒后把语音写进文件第 4 秒的位置：

```
[exp] engine resumed at t=0.20s
[exp] wrote speech at 4.0s after 1.2s
[  5.48s] interim text='今天'
[  6.28s] interim text='今天天气很好'
[  9.74s] final   text='今天天气很好，我们一起去公园散步吧。'
```

结论：**引擎按 ~1 倍速渐进读取文件并流式返回结果**，所以"边说边识别"成立。

### 延迟对比（约 4 秒语音）

| 阶段 | v1（一次性文件） | v2（流式，当前） |
| --- | --- | --- |
| 建连（~1.7s） | 松手后才付 | **与说话重叠** |
| 首个文字出现 | 松手后 | **开始说话后约 2.2s** |
| 松手 → 最终文本 | ~5s | **4.3 / 5.7 / 5.2 s（三次）** |

### v2 尾巴为什么还有 4-5 秒

1. 引擎启动后要 ~1.5s 完成云端握手，这期间它还没开始读文件 → 永久落后实时位置约 1.5-2s；
2. 读到文件末尾后还要跑 VAD 收尾 + 一次二次识别（~0.85-1.5s）；
3. 我们的截断只是让"落后量"不再增长，并不能让引擎追上实时。

## 三、下一步（迭代 3）：把尾巴压到 1s 级

### 路线 A：预热会话（pre-warmed session，改动小、见效快）

思路：**常驻一个已经建好连接的会话**，让它一直在读"静音"，读指针停在实时边缘。

- 启动程序时立刻开一个会话，写一个足够长的静音 WAV（例如 300s），让它按 1x 速度读；
- 按下热键时，把麦克风音频写到"读指针当前位置"（用会话启动时间 + 实测速率预测），使引擎始终贴着实时边缘；
- 松手时把文件截断到"当前位置 + 小尾巴"，让引擎立刻遇到 EOF 并收尾；
- 每次用完后立刻预热下一个会话。

预期：**松手到出字 ≈ 1.0-1.5s**（只剩 VAD 收尾 + 二次识别），首个文字在说话后 <1s 出现。

**首次实验结果（2026-09-13 15:52）**：

- 预热 3 秒后按预测位置写入语音，流程跑通；但**服务端会在静音约 29 秒后主动断开空闲流**
  （`OnError -100`，`disconnect_times: 1`，随后自动重连 `OnServiceReady`）。
  → 说明预热会话必须**每 20-25 秒回收重建一次**，不能一直挂着。
- 读指针预测需要标定：本次按 1.0 倍速估算、写指针放在预测位置前 0.3 秒（避免被跳过导致丢音），
  但实际速率有波动（握手 0.4-0.7s + 读取抖动），需要实测标定后再定策略。
- 本次 release→final 的计时因 stdout 被引擎日志句柄占住未能落盘，需要重跑一次带独立日志的实验。

结论：路线 A 仍值得做，但要做对两件事——**会话 20-25s 回收**、**读指针标定**；
如果这两点做扎实，尾巴有望从 4.5s 降到 1.0-1.5s。

### 路线 B：常驻服务 + 管道（改动大、最彻底）

思路：让引擎以"服务端模式"常驻（把 `\\.\pipe\ObricIme\oime-server` 在副本里改成独立名字避免与已装豆包冲突），复用它的连接池与**服务端自带的麦克风采集**，用 `rpc.dll` 的 `RpcPipe_KeyEvent` / `RpcPipe_PeekVoiceCommitUtf8` / `RpcPipe_AckVoiceCommit` 驱动。

预期：与豆包原生同构——**首字 0.3-0.6s，松手即上屏**，连 WAV 都不用落盘。
代价：需要还原 `rpc.dll` 至少 4 个函数的签名（可从 `tsf-oime-core.dll` 调用点反推），2-4 个工作日，失败风险中等。

### 路线 C：先做"感知优化"（可与 A/B 并行）

- 浮层里实时显示 interim 文本（v2 已具备数据，UI 需要再打磨）；
- 松手后立刻显示"… Transcribing"并给出预计剩余时间；
- 长口述按句分段提交，前几句可以先落字。

## 五、语言支持

同一套模型自动判断语言，无需配置。本机实测：

| 语言 | 实测输出 |
| --- | --- |
| 普通话 | `我确认程序能用，而且不错。请给出下一步的升级迭代规划。` |
| 粤语口述 | `请问听到吗？我讲广东话，一二三。` |
| 英文 | `Good morning, everybody. Today is Sunday. I'm going to go swimming with my daughter.` |

中英混说、粤普混说在同一次口述里也能正确出字。
